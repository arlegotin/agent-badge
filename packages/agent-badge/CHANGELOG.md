# @legotin/agent-badge

## 2.0.0

### Major Changes

- f81d9a4: Replace the Gist/global-runtime architecture with repository-owned Git data, private local discovery and checkpoints, exact repository runtime pins, contribution import and explicit clone activation. Requires Node ^24.0.0 || ^26.0.0. Usage remains partial when providers cannot certify amounts or attribution. Execution is supported on Linux and macOS. Native Windows actions are unsupported and reject before writes; with WSL2, run both the coding agent and Badge inside Linux. Hosted private-image rendering remains unverified. The 250ms pre-push optimization target remains unmet; the two-second hard budget remains.
