# Security

Supported execution requires Linux or macOS. Native Windows actions return `unsupported-platform` (exit 3) before setup or usage writes. WSL2 requires both the coding agent and Badge to run inside Linux; it does not imply discovery of native Windows histories.

Use GitHub private vulnerability reporting for this repository rather than publishing sensitive evidence in an issue. Reports should use synthetic reproductions and static diagnostic codes. Never attach private agent histories, prompts, transcripts, credentials, local source paths or provider session IDs.

Version 2 is a breaking repository-native replacement. It validates outbound schemas, bounded input objects, opaque identities, causal closure and immutable data trees; private discovery/checkpoints stay in Git's common directory. Normal Git authentication authorizes repository writers but does not attest the truth of their self-reported usage. Hashes provide identity/integrity, not billing verification.

Review exact runtime pins and native project hooks before activation. Setup never grants native trust, edits global provider settings or treats hook payloads as numeric receipts. Automatic operations use a two-second total supervisor budget; Native Windows execution is unsupported. Keep Git/Node/provider tools updated according to their own security guidance.

Trusted contribution CI imports accepted sanitized blobs using the approved installed runtime and lock; it does not execute Badge code from a proposal checkout. Remote doctor is read-only and does not probe credentials or write permissions. Private image rendering, actual hosted policy, and private-image delivery require external verification before claims are made. The hosted platform matrix must validate safe native Windows rejection.

Uninstall removes exact owned activation/integrations and retains unsynced journals, accepted history, unknown files and active/unknown leases. Edited ownership or interrupted third-state snapshots require action. Do not discard evidence or reseed shared history from a possibly stale private backup.
