# Historical Gist architecture

Gist setup belongs to the unsupported previous architecture. The repository-native replacement does not create, update, migrate or delete old Gists. Existing external data is left untouched; old aggregate totals cannot be added to new receipts without proving nonoverlap.

Use [installation](INSTALL.md), [CLI](CLI.md) and [recovery](RECOVERY.md) for the replacement. No live Gist endpoint or credentials are required.
